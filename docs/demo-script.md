# Demo recording script (~90 seconds, one take, no cuts)

## Setup
- Tab open, key pasted in the key box (masked, never visible on screen), one scam line ready in the textarea.
- Slow cursor. Hold every verdict screen for 2 seconds so a judge can read it.

## 0:00–0:10 — Hero
Show the page (/shield + tagline). Say: "This is SableShield. It stops scam calls — live, while you're still on the call."

## 0:10–0:45 — Scam demo
Tap "Demo: Scam Call". As lines appear, call out the flags:
- "Bank security call."
- "'Account BLOCKED in 2 hours' — urgency flag, the second it is spoken."
- "'Share the OTP' — critical flag. Real banks never ask for this."
- "'Do not tell anyone' — isolation flag."
- On the verdict, hold 2 seconds: "SCAM DETECTED — HANG UP NOW. 94% scam. Before the money moves."
- Tap Hang Up: "And the user confirms every action — the app never acts alone."

## 0:45–1:05 — Safe contrast
Tap "Demo: Safe Call" (card delivery). Say: "THIS CALL LOOKS SAFE — 8% risk. Same engine, opposite verdict — with reasons, so you can trust it both ways."

## 1:05–1:30 — Live mode (the most important shot)
Paste your own line (one the demo never scripted), tap Analyse. When the Gemma verdict appears, say: "Same verdict — on words the demo never scripted. Live, by Gemma 4, open weights."

## 1:30–1:40 — Close
Say: "On-device. No recording, no storage. Only open weights make this legal — that's why it's open-source." Show the repo / live demo link on screen, then stop.
