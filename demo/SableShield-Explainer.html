Problem

Scammers steal billions.
One phone call at a time.

You find out only after the money is gone. And every protection acts after the fact — blocking a number, reporting it, all of it happens after the call.

Say: Trust is exploited in real time, but protection always arrives late.
What is open source?

The recipe is public,
not secret.

Open source means the code and the model's weights are public — anyone can inspect them, run them, change them. Closed means only the company has them; you only get an API, never the model itself.

What are weights?

The billions of numbers inside the model. During training, these numbers get tuned — and those numbers are the model's entire knowledge.

What do open weights mean?

These numbers are public. Download them, run them on your own machine. So the model is yours — not dependent on any server.

Say: Weights = the model's numbers. Open = numbers public. Closed = numbers secret.
Where is it in my app?

Two places. Both open.

1 · The model is open — Gemma 4

In live mode, Gemma 4 gives the verdict (gemma-4-26b-a4b-it). Its weights are public, so the same model can run on a phone.

2 · The code is open — MIT

The whole project is in a public repo: website, demo, live mode, server — anyone can read and run it.

The demo's scripted verdicts are not AI — they exist for on-stage reliability. The real AI is in live mode, with the Gemma verdict.

Say: Model open + code open. Demo is scripted, live mode is real AI — that honesty is the credibility.
Why only open weights?

Closed AI cannot do
this job at all.

Privacy

Closed AI would have to send a live call to a server — the very violation we are protecting against.

Speed

A 2–5 second cloud round-trip is too slow. By then the OTP is gone. On-device warns in milliseconds.

Cost

If every call costs an API fee, a free product is impossible. Open weights cost zero per call.

Offline

Cloud AI dies in villages and on weak networks. On-device keeps working there.

Say: Four reasons in one line — privacy, speed, cost, offline. Closed fails all four.
How it works

Watch. Flags. Verdict.

Scam demo: lines appear, every scam line gets a flag — urgency, OTP, isolation. Verdict: SCAM DETECTED — HANG UP NOW, 94%. Safe call: 8% risk, with reasons. Live mode: paste your own line, Gemma gives the verdict.

If anyone asks

Short answers, ready.

Why not GPT?

It is closed — the call goes to its server, it costs money, it is slow, it does not work offline.

When on a real call?

No app can tap cellular call audio. Production paths: VoIP dialer, carrier/OEM integration, speakerphone + mic fallback.

Different from Truecaller?

It blocks numbers, after the fact. We read content, during the call — a new number gets caught too.

No key?

The rule-based fallback runs — the same patterns, without AI. The product never fails.

make this legal.
