# Roadmap

## v1 — Demo (done, 2026-10-26)
Web prototype: scripted scam/safe demos, live Gemma analysis, rule-based fallback, public repo, GitHub Pages demo.

## v1.1 — Speakerphone MVP (next)
Mic + on-device speech-to-text + local Gemma verdict on any call via speakerphone. Works on any phone, no partnerships needed. Fragile by nature — an MVP, not the end state.

## v2 — VoIP dialer app
A calling app that carries the call itself, so audio is ours: full-quality on-device transcription + verdict + mid-call alert, no speakerphone needed. Only covers calls made through the app.

## v3 — Carrier / OEM integration
Protection inside the phone's own dialer (Pixel Call Screen model). Full coverage on every call. Needs partnerships — the scale play, not a weekend build.

Planned, not built: v1.1–v3 are roadmap, not shipped features.
